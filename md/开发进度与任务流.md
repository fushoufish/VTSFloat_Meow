# VTSFloat_Meow 开发进度与任务流

更新于 2026-11-13。CMake 项目版本为 `1.3.0`，正式发布附件由 GitHub Actions 构建。

## 已接入

| 模块 | 当前进度 |
| --- | --- |
| 接收与启动 | 优先连接 `VTubeStudioSpout`，支持其他 Spout2 源及第三方应用快捷启动。收到画面后才启用「完成」。 |
| 工具栏与教程 | 缩放、语言、比例和窗口模式等入口图标化。首次点击「完成」依次介绍锁定、快捷键与缩放。 |
| 画面编辑 | 裁剪、羽化与旋转、色阶和曲线、混合、曝光、清晰度、暗角、内部和外部阴影。 |
| 设置与缓存 | 独立缓存目录、旧设置迁移、输入框横向拖拽、界面缩放与边框样式即时保存。 |
| VTube Studio API | 收到 Spout2 画面后自动连接，授权栏可跳过，再从「完成」左侧重新连接。 |
| 更新 | GitHub 原生与备用线路、数字版本比较、下载校验、保存设置、替换与回滚。 |
| 网站 | 提供 GitHub、CNB 和蓝奏云下载入口。客户端自动更新使用 GitHub Release。 |

## 验证记录

- Windows x64 Release 已编译。用独立 Spout2 测试源验证了三步教程、旧配置迁移、阴影面板和距离拖拽持久化。
- 用本机模拟 VTube Studio API 验证了自动发起授权、跳过、重新连接和再次跳过，并确认授权请求中的作者字段为 `fushoufish——咕噜灵波`。
- 真机已验证新版程序可启动并接收 VTube Studio 的 Spout2 流。阴影在复杂画面下的效果与开销，以及授权窗中作者名的实际显示待回归。

## 继续开发与发布

1. 实机复测 API 初次授权、跳过后重连、已授权用户升级和关闭旧版后的单实例释放。
2. 在 24 FPS 视频和拖动窗口场景复查混合与阴影，并检查高缩放下各语言的文字宽度。
3. 确定正式版本号，更新 CMake 项目版本，运行 Release 构建、CTest 与本地化检查。
4. 用可更新的旧构建验证原生线路、备用线路、成功清理和失败回滚，再发布 GitHub Release 及 EXE 附件。
5. 核对 GitHub Pages 下载入口、CNB 镜像的 Release 和 EXE 附件。
