项目网站隐私政策

本政策适用于 VTSFloat_Meow 的项目介绍与文档网站。

信息收集与本地存储

本网站不设置访问统计、广告追踪或要求填写个人信息的表单，也不主动收集访问者的个人信息。网站会在浏览器的 localStorage 中保存您选择的界面语言，以便下次访问时使用；您可以通过清除本网站的数据删除该设置。

托管与外部资源

本网站由 GitHub Pages 托管，软件下载由 GitHub Releases 提供。页面还会从 GitHub 的资源域名加载 GitHub 图标。访问网站、加载外部资源或下载文件时，浏览器会向相关服务发送 IP 地址等连接所需的技术信息；GitHub 如何处理这些信息，请参阅 GitHub 隐私声明。

点击外部链接后，相应网站适用其自身的隐私政策。

桌面程序

网站与桌面程序的处理范围不同。桌面程序的本地模型处理和 localhost 通信说明，请参阅仓库中的 README 与 代码签名政策中的程序隐私说明。

联系

如有隐私问题，请通过 项目 GitHub 仓库联系维护者。公开 Issue 中请勿提供敏感个人信息。

Project website privacy policy

This policy applies to the VTSFloat_Meow project introduction and documentation website.

Information collection and local storage

We do not directly collect personal information through this website. It does not use visitor analytics, advertising trackers, or forms requesting personal information. The website saves your selected interface language in your browser's localStorage for future visits. You can remove this preference by clearing this site's browser data.

Hosting and external resources

The website is hosted on GitHub Pages, and software downloads are hosted on GitHub Releases. The page also loads a GitHub icon from GitHub's asset domain. When you visit, load external resources, or download files, your browser sends technical information needed for the connection, such as your IP address, to the relevant services. For GitHub's handling of this information, see GitHub's Privacy Statement.

External websites linked from this site are subject to their own privacy policies.

Desktop application

The website and desktop application have different processing scopes. For the application's local model processing and localhost communication, see the repository's README and the application privacy section of the Code signing policy.

Contact

For privacy questions, contact the maintainer through the project's GitHub repository. Please do not post sensitive personal information in public issues.
